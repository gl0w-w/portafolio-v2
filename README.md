# Portafolio Personal - Iván Sepúlveda

    Este repositorio contiene el código fuente de mi portafolio personal, diseñado y desarrollado con un enfoque en la experiencia de usuario,

animaciones fluidas y rendimiento óptimo.

    ## Arquitectura y Tecnologías

    El proyecto fue construido utilizando una arquitectura moderna orientada a componentes, separando la estructura estática de la interactividad para

asegurar tiempos de carga casi instantáneos.

    * **Astro**: Utilizado como framework principal por su capacidad de generar sitios estáticos ultrarrápidos y su arquitectura de "Island

Architecture" para cargar solo el JavaScript necesario.  
 _ **React**: Implementado para los componentes altamente interactivos y dinámicos que requieren manejo de estado complejo en el lado del cliente.  
 _ **Tailwind CSS**: Empleado para la estilización del sitio y el diseño responsivo, manteniendo un sistema de diseño consistente.  
 \* **Framer Motion**: Integrado para el desarrollo de animaciones, transiciones de elementos y efectos basados en el comportamiento del usuario (como
el desplazamiento de la página).

    ## Características Principales

    * **Efectos Visuales Avanzados**: Implementación de texto encriptado dinámico, marquesinas reactivas a la velocidad de desplazamiento y desenfoques

de fondo avanzados.  
 _ **Renderizado Estático**: Todo el sitio se compila a HTML y CSS estático en tiempo de construcción, lo que garantiza tiempos de respuesta mínimos
y excelente SEO.  
 _ **Diseño Responsivo**: Adaptación total a dispositivos móviles, tablets y monitores de alta resolución.  
 \* **Tema Oscuro**: Esquema de colores monocromático diseñado para optimizar el contraste, la legibilidad y transmitir una estética minimalista.

    ## Ejecución Local

    Para correr este proyecto en tu entorno local, sigue estos pasos:

    1. Clona el repositorio en tu máquina.
    2. Instala las dependencias necesarias ejecutando `npm install`.
    3. Inicia el servidor de desarrollo con el comando `npm run dev`.
    4. Abre tu navegador web en la dirección proporcionada por la consola (usualmente localhost:4321).

    ## Despliegue

    Este sitio está construido para ser desplegado de manera estática. Actualmente se encuentra optimizado para integrarse directamente con plataformas

de Edge Computing como Cloudflare Pages, asegurando distribución global y latencia mínima.
